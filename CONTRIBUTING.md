# Contributing to reporadar

First off, thank you for considering contributing to reporadar! It's people like you that make open source such a great community.

## Development Setup
1. Fork and clone the repo
2. Run `npm install`
3. Make your changes in a new branch

## Code Style
- We use pure Node.js with zero dependencies. Please do not add external npm packages unless absolutely necessary.
- Use JSDoc for all new functions.

## Submitting a Pull Request
1. Ensure the CI passes.
2. Add a descriptive title and explain the "why" behind your changes.
